# JM-EHunter

[EHunter](https://github.com/hanFengSan/eHunter) をベースにした拡張版マンガリーダー。E-Hentai と 18comic（禁漫天堂）を完全にサポートしています。

## 新機能

このフォークでは、オリジナルの EHunter に以下の拡張機能を追加しています：

### 18comic（禁漫天堂）のサポート
- 18comic のギャラリーページと完全互換
- プラットフォームを自動検出し、テーマを適用
- 18comic にはオレンジのテーマ、E-Hentai サイトにはグリーンのテーマを使用

### アニメーション速度コントロール
- ページめくりアニメーションの速度調整が可能（0.5倍 ～ 2.0倍）
- 全てのアニメーションモードで統一された基準時間（0.70秒）を採用
- トップバーからリアルタイムで速度調整が可能

### アニメーション反転スイッチ
- マウスホイールとキーボードの方向キーによるページめくりアニメーションの方向を同時に反転
- トップバーのアニメーション速度設定の隣に配置
- ユーザー個人の好みに合わせてアニメーションの動作をカスタマイズ可能

### アニメーション動作の改善
- アニメーションの上書き：連続したページめくり時に前のアニメーションの完了を待機しない
- 4つのアニメーションモード：水平スライド、リアルな本めくり（3D）、回転（2D）、垂直スライド
- キーボードとマウスホイールの操作における物理的な方向のロジックを統一

### UI の改善
- 全てのインターフェース要素のブランド名を "JM-EHUNTER" に更新
- プラットフォーム専用のカラーテーマ（18comic はオレンジ、E-Hentai はグリーン）
- アニメーションコントロールに素早くアクセスできる拡張トップバー

## オリジナル EHunter から引き継いだ機能

- 複数の読書モード（スクロールと見開き・本モード）
- サムネイルビューとクイックナビゲーション
- カスタマイズ可能なページレイアウト（単一ページ/見開き）
- RTL（右から左） / LTR（左から右）の読書方向をサポート
- キーボードショートカットとマウスホイールナビゲーション
- ダウンロード機能
- 多言語サポート（中国語、英語、日本語）

## インストール

これは Tampermonkey や類似のブラウザ拡張機能用のユーザースクリプトです。

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. プロジェクトをビルドします（「開発」セクションを参照）。
3. Tampermonkey のダッシュボードを開きます。
4. 「ユーティリティ（Utilities）」タブをクリックし、[Release](https://github.com/FPV-G/JM-EHunter/releases) からダウンロードした `jmehunter.iife.js` を Tampermonkey のウィンドウにドラッグ＆ドロップします。
5. 「インストール」をクリックします。

スクリプトは E-Hentai および 18comic のギャラリーページで自動的に有効になります。

## 開発

### 動作環境（前提条件）
- Node.js 14 以上
- npm または yarn

### セットアップ

```bash
npm install
```

### 開発用ビルド

```bash
npm run dev
```

### 本番用ビルド

```bash
npm run build-prod
```

出力ファイルは `dist/jmehunter.iife.js` に生成されます。

## 使用方法

### アニメーション速度
見開き（本）モード時、トップバーの「アニメーション速度」ドロップダウンメニューを使用してページめくりの速度を調整できます：
- 0.5x（遅い）
- 0.75x
- 1.0x（デフォルト）
- 1.25x
- 1.5x
- 2.0x（速い）

### アニメーション反転
トップバーの「アニメーション反転」スイッチを切り替えると、キーボードの方向キーとマウスホイールによるアニメーションの方向を反転できます。

### キーボードショートカット
- 右矢印キー：右から左へのアニメーションをトリガー
- 左矢印キー：左から右へのアニメーションをトリガー
- 上/下矢印キー：スクロールモードでのページめくり
- その他のショートカット：設定ダイアログを参照

## プロジェクトアーキテクチャ

現在のプロジェクトは `Vite + Vue 3 + TypeScript` に基づいており、主要な目標は以下の通りです：
1. 対象サイトのページ内にリーダーUIを注入する
2. プラットフォームの解析ロジックとリーダーのレンダリングロジックを分離し、拡張とメンテナンスを容易にする

主なディレクトリの役割は以下の通りです：

```
|-JM-EHunter
  |-src
  |  |-main.ts               // エントリポイント：初期化とアプリケーションのマウント
  |  |-config.ts             // ランタイム設定
  |  |-platform/             // プラットフォーム層（サイト識別、初期化、プラットフォームサービスファクトリ）
  |     |-detector.ts        // ドメイン/環境の識別
  |     |-initializer.ts     // プラットフォームの初期化プロセス
  |     |-factory.ts         // プラットフォームサービスインスタンスの作成
  |     |-eh/                // EH/EXH プラットフォームの実装
  |     |-c18/               // 18comic プラットフォームの実装
  |     |-base/              // クロスプラットフォームの基礎機能（リクエスト、キュー、リトライなど）
  |
  |-core
  |  |-App.vue               // リーダーのルートコンポーネント
  |  |-components/           // ビュー層：本モード、スクロールモード、サムネイル、ツールバー、ポップアップなど
  |  |-service/              // ビジネスサービス層（ギャラリーデータ、ダウンロード、リトライ戦略）
  |  |-store/                // 状態管理（アプリ状態、イベント、i18n、レイアウト設定）
  |  |-model/                // ドメインモデル（レイアウト、見開き、サムネイル展開など）
  |  |-utils/                // ユーティリティ関数
  |  |-style/                // グローバルスタイルとテーマ変数
  |
  |-public/                  // 静的アセット
  |-dist/                    // ビルド成果物
  |-specs/                   // 機能設計および仕様ドキュメント
  |-misc/                    // 説明ドキュメントおよび補助資料
```

簡略化した呼び出しフロー：
`main.ts -> platform 初期化（サイト識別 + プラットフォームサービス作成）-> core リーダーのマウント -> コンポーネントのレンダリングとインタラクション -> service/store が連携してデータ読み込みと状態更新を実行`
